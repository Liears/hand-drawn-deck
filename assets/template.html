改动集中在重试函数的十几行里

def retry(call, attempts=3):
    for i in range(attempts):
        try:
            return call()
        except TransientError:
            sleep(2 ** i + jitter())
    raise GiveUp(attempts)

读这段代码看三处

退避上限由 attempts 决定，默认三次。

只对可恢复错误重试，其余直接抛出。

抖动打散同一时刻的重试。
